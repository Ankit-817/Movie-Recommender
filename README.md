# 🎬 Movie Recommendation System

A content-based movie recommendation system built using Python and Machine Learning. It recommends movies based on similarities in their genres, keywords, cast, crew, and overview.

🔗 **Live Demo:** https://movie-recommendation-system-bwrh.onrender.com/


## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- CountVectorizer
- Cosine Similarity
- Pickle
- Jupyter Notebook

## ⚙️ How It Works

```text
  TMDB Dataset
       ↓
Data Cleaning
       ↓
Feature Extraction
       ↓
Text Preprocessing
       ↓
Porter Stemming
       ↓
CountVectorizer
       ↓
Cosine Similarity
       ↓
Movie Recommendations
